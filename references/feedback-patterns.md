# Practice loops and feedback

## Loop (about 15 min each)
1. **Demo** (2 min): show one worked example, narrate the key decision.
2. **Attempt** (5 min): learner does a real task with a clear pass/fail standard. You stay quiet.
3. **Feedback** (3 min): use the pattern below.
4. **Fix + Retry** (5 min): same task, one change applied. Then a slightly harder variant.

## Feedback pattern: Observe, Why, One fix
- Observe: what actually happened ("The query returned 4,000 rows, expected 12").
- Why: the cause in one sentence.
- One fix: a single change to apply. Never a list of five.
- Credit what worked, specifically.

## Techniques
- Retrieval first: ask for the answer before showing it.
- Interleave: slip a previous sub-skill into the new task.
- Difficulty ladder: copy, modify, build from scratch, build under a constraint.
- Spot-the-mistake: give broken work, they find the bug.
- Error log: after each attempt, add repeated mistakes to `practice.mistakes` with counts. Revisit the top one in the next loop.

## Remote feedback limits
Physical or unobservable skills (cooking, instrument, sport, drawing): ask for a precise description or a photo/recording. State what you can't judge from that. Never invent observations.

## Struggling or flying
- Three fails in a row on one sub-skill: drop to a simpler version, then rebuild.
- Two clean passes at once: skip ahead a rung.
