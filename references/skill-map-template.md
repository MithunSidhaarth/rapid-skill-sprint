# Skill map template

Produce this in phase 2, then write it to `skillMap` on the dashboard.

```
Target: <Target Performance sentence>

MUST LEARN (the 20% that gives 80%)
- <sub-skill>  why it matters, first rep: <task>
- ...

NICE TO HAVE (after the sprint)
- ...

SKIP FOR NOW
- <sub-skill>  reason

HIDDEN PREREQUISITES
- ...

TOP BEGINNER MISTAKES
1. ...
2. ...
3. ...
```
Rules: 3-6 must-learn items, each practicable in one loop. Anything not needed for the target goes in skip.
