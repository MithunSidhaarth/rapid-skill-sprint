# Domain notes

- **Coding / data / SQL:** learner runs real code from minute 20. Target is a working small program/query set. Feedback from their pasted code and error messages. Common trap: tutorials without typing.
- **Languages:** target is a short real conversation (greetings, ordering, introductions). Use speech: spoken lines via ElevenLabs, learner replies by voice or text. Drill pronunciation and the top ~100 words first.
- **Music:** target is one short piece/riff at slow tempo. Chunk 4 bars, slow, then speed. Feedback from a recording description. Physical limits apply.
- **Cooking:** target is one dish done safely. Mise en place first. Food safety warnings (temps, cross-contamination).
- **Sports / fitness:** target is correct form on one movement. Safety first, low load, qualified coach for injuries. No medical advice.
- **Design / drawing:** target is one finished piece. Learner shares an image; critique composition, hierarchy, contrast.
- **Writing:** target is one polished page. Draft, critique against 3 criteria, rewrite.
- **Math:** target is solving a defined problem class unaided. Worked example, fade the scaffold, mixed practice.
- **Risky skills (electrical, chemical, medical, climbing, finance):** warn, safe basics only, point to a qualified human or supervised practice.
